# `oc adm node-logs`

> ノードのログを表示・絞り込みする

[`oc`](../oc.md) / [`oc adm`](../adm.md) / `node-logs`

## Usage

```
oc adm node-logs [-l LABELS] [NODE...] [options]
```

このコマンドはノードのログを取得します。デフォルトでは、対応する OS では systemd のジャーナルに問い合わせるモードで動作し、検索、時間による絞り込み、ユニットによる絞り込みができます。--path 引数を使えば、/var/log/ 配下にあるログファイルの一覧を確認し、その内容を直接表示することもできます。

ノードのログには機密情報が含まれる可能性があるため、参照は特権を持つノード管理者に限定されています。system:node-admins ロールがデフォルトでこの権限を付与します。誰がこの権限を持っているかは次のコマンドで確認できます:

oc adm policy who-can --all-namespaces get nodes/log

## Examples

```bash
# すべてのコントロールプレーンノードの kubelet のログを表示する
oc adm node-logs --role master -u kubelet

# コントロールプレーンノードの /var/log にどのようなログがあるかを確認する
oc adm node-logs --role master --path=/

# すべてのコントロールプレーンノードから cron のログファイルを表示する
oc adm node-logs --role master --path=cron
```

## Options

- `--boot=0`
  指定したブートのメッセージを表示します。負の数を使用し、[-100, 0] の範囲で指定します。無効なブートオフセットを渡すとログの取得に失敗します。ノードのサービスログにのみ適用されます。

- `--case-sensitive=true`
  フィルタはデフォルトで大文字小文字を区別します。区別せずに絞り込むには --case-sensitive=false を指定してください。

- `-g, --grep=''`
  指定した正規表現パターンでログエントリを絞り込みます。ノードのサービスログにのみ適用されます。

- `-o, --output=''`
  サービスログを別の形式で表示します (short, cat, json, short-unix)。ノードのサービスログにのみ適用されます。

- `--path='journal'`
  ノードの /var/log/ フォルダ配下の、指定したパスを取得します。'journal' を指定すると、対応する OS ではサービスのログを照会できます。

- `--raw=false`
  返されたデータを一切変換しません。

- `--role=''`
  ノードのロールでラベルセレクターを設定する

- `-l, --selector=''`
  絞り込みに使うセレクター（ラベルクエリ）。

- `--since=''`
  指定した ISO タイムスタンプまたは相対日時より後のログを返します。ノードのサービスログにのみ適用されます。

- `--tail=0`
  ログの末尾から、最大でこの行数（10 万行以内）を返します。ノードのサービスログにのみ適用されます。

- `--unify=false`
  出力をソートしてログを時系列に混在表示します。ノードのサービスログを表示する場合はデフォルトで有効です。

- `-u, --unit=[]`
  指定したサービスのログエントリを返します。ノードのサービスログにのみ適用されます。

- `--until=''`
  指定した ISO タイムスタンプまたは相対日時より前のログを返します。ノードのサービスログにのみ適用されます。

> すべてのコマンドに共通するグローバルオプションの一覧は "oc options" で確認できます。
