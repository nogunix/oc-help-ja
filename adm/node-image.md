# `oc adm node-image`

> 既存のクラスタにノードを追加する

[`oc`](../oc.md) / [`oc adm`](../adm.md) / `node-image`

これらのサブコマンドを使うと、OpenShift クラスタに目的のノードを追加するための ISO イメージを作成し、その過程を監視できます。

## Subcommands

- [`create`](node-image/create.md) — 対象クラスタに追加するノードを起動するための ISO イメージを作成する
- [`monitor`](node-image/monitor.md) — OpenShift クラスタに追加中の新しいノードを監視する

> 各コマンドの詳細については "oc adm node-image `<command>` --help" を使用してください。
