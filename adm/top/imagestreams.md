# `oc adm top imagestreams`

> イメージストリームの使用量統計を表示する

[`oc`](../../oc.md) / [`oc adm`](../../adm.md) / [`oc adm top`](../top.md) / `imagestreams`

## Usage

```
oc adm top imagestreams [flags] [options]
```

このコマンドは、プラットフォームが管理するすべてのイメージストリームを分析し、現在の使用量統計を表示します。

エイリアス: imagestreams, imagestreams, is

## Examples

```bash
# イメージストリームの使用量統計を表示する
oc adm top imagestreams
```

> すべてのコマンドに共通するグローバルオプションの一覧は "oc options" で確認できます。
