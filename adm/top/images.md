# `oc adm top images`

> イメージの使用量統計を表示する

[`oc`](../../oc.md) / [`oc adm`](../../adm.md) / [`oc adm top`](../top.md) / `images`

## Usage

```
oc adm top images [flags] [options]
```

このコマンドは、プラットフォームが管理するすべてのイメージを分析し、現在の使用量統計を表示します。

## Examples

```bash
# イメージの使用量統計を表示する
oc adm top images
```

> すべてのコマンドに共通するグローバルオプションの一覧は "oc options" で確認できます。
