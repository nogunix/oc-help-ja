# `oc adm certificate`

> 証明書要求を承認または拒否する

[`oc`](../oc.md) / [`oc adm`](../adm.md) / `certificate`

## Usage

```
oc adm certificate SUBCOMMAND [options]
```

証明書リソースを変更します。

## Subcommands

- [`approve`](certificate/approve.md) — 証明書署名要求を承認する
- [`deny`](certificate/deny.md) — 証明書署名要求を拒否する

> 各コマンドの詳細については "oc adm certificate `<command>` --help" を使用してください。

> すべてのコマンドに共通するグローバルオプションの一覧は "oc options" で確認できます。
