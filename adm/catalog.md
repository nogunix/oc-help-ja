# `oc adm catalog`

> OpenShift の OLM カタログを管理するためのツール

[`oc`](../oc.md) / [`oc adm`](../adm.md) / `catalog`

## Usage

```
oc adm catalog [flags] [options]
```

このツールは、Operator Lifecycle Manager 向けのカタログの内容を取り出し、ミラーするために使用します。

これらのサブコマンドを使うと、カタログの内容をレジストリ間でミラーできます。

## Subcommands

- [`mirror`](catalog/mirror.md) — operator-registry のカタログをミラーする

> 各コマンドの詳細については "oc adm catalog `<command>` --help" を使用してください。

> すべてのコマンドに共通するグローバルオプションの一覧は "oc options" で確認できます。
