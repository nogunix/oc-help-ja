# `oc adm upgrade status`

> 現在のクラスタバージョン更新、またはマルチアーキテクチャ移行の状況を表示する

[`oc`](../../oc.md) / [`oc adm`](../../adm.md) / [`oc adm upgrade`](../upgrade.md) / `status`

## Usage

```
oc adm upgrade status [flags] [options]
```

## Options

- `--details='none'`
  選択したセクションの詳細な出力を表示します。none, all, nodes, health, operators のいずれかを指定します

> すべてのコマンドに共通するグローバルオプションの一覧は "oc options" で確認できます。
