# `oc config get-users`

> kubeconfig に定義されたユーザーを表示する

[`oc`](../oc.md) / [`oc config`](../config.md) / `get-users`

## Usage

```
oc config get-users [flags] [options]
```

## Examples

```bash
# oc が把握しているユーザーを一覧する
oc config get-users
```

> すべてのコマンドに共通するグローバルオプションの一覧は "oc options" で確認できます。
