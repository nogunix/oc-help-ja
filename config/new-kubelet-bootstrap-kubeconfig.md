# `oc config new-kubelet-bootstrap-kubeconfig`

> 新しい kubelet 用 /etc/kubernetes/kubeconfig を生成し、サーバーに信頼させて表示する

[`oc`](../oc.md) / [`oc config`](../config.md) / `new-kubelet-bootstrap-kubeconfig`

## Usage

```
oc config new-kubelet-bootstrap-kubeconfig [options]
```

## Examples

```bash
# 新しい kubelet bootstrap kubeconfig を生成する
oc config new-kubelet-bootstrap-kubeconfig
```

> すべてのコマンドに共通するグローバルオプションの一覧は "oc options" で確認できます。
