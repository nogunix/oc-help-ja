# `oc config get-clusters`

> kubeconfig に定義されたクラスタを表示する

[`oc`](../oc.md) / [`oc config`](../config.md) / `get-clusters`

## Usage

```
oc config get-clusters [flags] [options]
```

## Examples

```bash
# oc が把握しているクラスタを一覧する
oc config get-clusters
```

> すべてのコマンドに共通するグローバルオプションの一覧は "oc options" で確認できます。
