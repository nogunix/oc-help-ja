# `oc config use-context`

> kubeconfig ファイルの current-context を設定する

[`oc`](../oc.md) / [`oc config`](../config.md) / `use-context`

## Usage

```
oc config use-context CONTEXT_NAME [options]
```

エイリアス: use-context, use

## Examples

```bash
# minikube クラスタ用のコンテキストを使う
oc config use-context minikube
```

> すべてのコマンドに共通するグローバルオプションの一覧は "oc options" で確認できます。
