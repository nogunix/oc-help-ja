# `oc config delete-user`

> 指定したユーザーを kubeconfig から削除する

[`oc`](../oc.md) / [`oc config`](../config.md) / `delete-user`

## Usage

```
oc config delete-user NAME [options]
```

## Examples

```bash
# minikube ユーザーを削除する
oc config delete-user minikube
```

> すべてのコマンドに共通するグローバルオプションの一覧は "oc options" で確認できます。
