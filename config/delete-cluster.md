# `oc config delete-cluster`

> 指定したクラスタを kubeconfig から削除する

[`oc`](../oc.md) / [`oc config`](../config.md) / `delete-cluster`

## Usage

```
oc config delete-cluster NAME [options]
```

## Examples

```bash
# minikube クラスタを削除する
oc config delete-cluster minikube
```

> すべてのコマンドに共通するグローバルオプションの一覧は "oc options" で確認できます。
