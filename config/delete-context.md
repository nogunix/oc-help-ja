# `oc config delete-context`

> 指定したコンテキストを kubeconfig から削除する

[`oc`](../oc.md) / [`oc config`](../config.md) / `delete-context`

## Usage

```
oc config delete-context NAME [options]
```

## Examples

```bash
# minikube クラスタ用のコンテキストを削除する
oc config delete-context minikube
```

> すべてのコマンドに共通するグローバルオプションの一覧は "oc options" で確認できます。
