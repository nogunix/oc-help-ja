# `oc adm upgrade status`

> Display the status of the current cluster version update or multi-arch migration

[`oc`](../../oc.md) / [`oc adm`](../../adm.md) / [`oc adm upgrade`](../upgrade.md) / `status`

## Usage

```
oc adm upgrade status [flags] [options]
```

## Options

- `--details='none'`
  Show detailed output in selected section. One of: none, all, nodes, health, operators

> Use "oc options" for a list of global command-line options (applies to all commands).
