# `oc adm top images`

> Show usage statistics for images

[`oc`](../../oc.md) / [`oc adm`](../../adm.md) / [`oc adm top`](../top.md) / `images`

## Usage

```
oc adm top images [flags] [options]
```

This command analyzes all the images managed by the platform and presents current usage statistics.

## Examples

```bash
# Show usage statistics for images
oc adm top images
```

> Use "oc options" for a list of global command-line options (applies to all commands).
