# `oc adm top imagestreams`

> Show usage statistics for image streams

[`oc`](../../oc.md) / [`oc adm`](../../adm.md) / [`oc adm top`](../top.md) / `imagestreams`

## Usage

```
oc adm top imagestreams [flags] [options]
```

This command analyzes all the image streams managed by the platform and presents current usage statistics.

Aliases:
imagestreams, imagestreams, is

## Examples

```bash
# Show usage statistics for image streams
oc adm top imagestreams
```

> Use "oc options" for a list of global command-line options (applies to all commands).
