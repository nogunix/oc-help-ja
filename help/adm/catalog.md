# `oc adm catalog`

> Tools for managing the OpenShift OLM Catalogs

[`oc`](../oc.md) / [`oc adm`](../adm.md) / `catalog`

## Usage

```
oc adm catalog [flags] [options]
```

This tool is used to extract and mirror the contents of catalogs for Operator Lifecycle Manager.

The subcommands allow you to mirror catalog content across registries.

## Subcommands

- [`mirror`](catalog/mirror.md) — Mirror an operator-registry catalog

> Use "oc adm catalog `<command>` --help" for more information about a given command.

> Use "oc options" for a list of global command-line options (applies to all commands).
