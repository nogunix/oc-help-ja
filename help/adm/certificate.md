# `oc adm certificate`

> Approve or reject certificate requests

[`oc`](../oc.md) / [`oc adm`](../adm.md) / `certificate`

## Usage

```
oc adm certificate SUBCOMMAND [options]
```

Modify certificate resources.

## Subcommands

- [`approve`](certificate/approve.md) — Approve a certificate signing request
- [`deny`](certificate/deny.md) — Deny a certificate signing request

> Use "oc adm certificate `<command>` --help" for more information about a given command.

> Use "oc options" for a list of global command-line options (applies to all commands).
