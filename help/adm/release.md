# `oc adm release`

> Tools for managing the OpenShift release process

[`oc`](../oc.md) / [`oc adm`](../adm.md) / `release`

This tool is used by OpenShift release to build images that can update a cluster.

The subcommands allow you to see information about releases, perform administrative actions inspect the content of the release, and mirror release content across image registries.

## Subcommands

- [`extract`](release/extract.md) — Extract the contents of an update payload to disk
- [`info`](release/info.md) — Display information about a release
- [`new`](release/new.md) — Create a new OpenShift release

> Use "oc adm release `<command>` --help" for more information about a given command.
