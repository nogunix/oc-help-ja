# `oc adm node-image`

> Add nodes to an existing cluster

[`oc`](../oc.md) / [`oc adm`](../adm.md) / `node-image`

The subcommands allow you to create an ISO image to be used for adding the desired nodes to an OpenShift cluster, and also to monitor the process.

## Subcommands

- [`create`](node-image/create.md) — Create an ISO image for booting the nodes to be added to the target cluster
- [`monitor`](node-image/monitor.md) — Monitor new nodes being added to an OpenShift cluster

> Use "oc adm node-image `<command>` --help" for more information about a given command.
