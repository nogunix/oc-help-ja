# `oc create service`

> Create a service using a specified subcommand

[`oc`](../oc.md) / [`oc create`](../create.md) / `service`

## Usage

```
oc create service [flags] [options]
```

Aliases:
service, svc

## Subcommands

- [`clusterip`](service/clusterip.md) — Create a ClusterIP service
- [`externalname`](service/externalname.md) — Create an ExternalName service
- [`loadbalancer`](service/loadbalancer.md) — Create a LoadBalancer service
- [`nodeport`](service/nodeport.md) — Create a NodePort service

> Use "oc create service `<command>` --help" for more information about a given command.

> Use "oc options" for a list of global command-line options (applies to all commands).
