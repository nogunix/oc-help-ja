# `oc image`

> Useful commands for managing images

[`oc`](oc.md) / `image`

## Usage

```
oc image COMMAND [flags] [options]
```

Manage images on OpenShift

These commands help you manage images on OpenShift.

## Subcommands

- [`append`](image/append.md) — Add layers to images and push them to a registry
- [`extract`](image/extract.md) — Copy files from an image to the file system
- [`info`](image/info.md) — Display information about an image
- [`mirror`](image/mirror.md) — Mirror images from one repository to another

> Use "oc image `<command>` --help" for more information about a given command.

> Use "oc options" for a list of global command-line options (applies to all commands).
